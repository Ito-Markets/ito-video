# Example project and source lineage

Ito-video is the Ito example project consuming the ECC `ecc-tasteforge` package.
Reusable engine code, interview/schema contracts, workflows, adapters and metadata
fixtures are maintained in ECC under `skills/taste-application/scripts`.
The pinned dependency is recorded in `requirements-tasteforge.txt`.

The metadata fixture `tasteforge/fixtures/flashethereal` originated in
`tasteforge (4).zip`, SHA-256
`ef06a606d3b528fbd939b05fadc25bf6674073a1e05a01e3aa6b9c9416fd6284`.
The later original standalone creative skills were recovered from
`ecc-taste-skills_1.zip`, SHA-256
`5e0dc440df4dcf6b2082a7dd59e1d6e9cc11d10166d4e1a19dc6c96478f4d2c8`.
ECC's `skills/taste-application/SOURCE.md` describes that source and focused fixes.

Raw reference media, generated media, meshes, `look.cube`, personal transcripts,
editor backups and provider credentials are not dependencies of this public
example. Local source and editor history are preserved outside the packaged
engine. A local endpoint reference is not proof that a provider workflow was
saved or a generation was executed.

This consolidation updates current tracked files without rewriting repository
history or changing repository visibility. Project-specific scripts, media and
creative history retain their ownership in this example project.
